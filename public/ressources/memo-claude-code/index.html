Le mémo Claude Code

Toutes les commandes slash et les raccourcis-prompts, classés par usage et expliqués en une ligne : à garder sous la main.

US Par Ugo Sartini

Claude Code cache des dizaines de commandes qui ne s'affichent nulle part tant qu'on ne tape pas /. Voici le mémo complet : chaque commande slash et chaque raccourci-prompt, classés par usage et expliqués en une ligne. À garder ouvert dans un onglet.

Comment lire ce mémo. Trois niveaux de fiabilité, assumés honnêtement : les commandes que j'utilise avec confiance, celles vues en cheatsheet à re-vérifier, et les raccourcis-prompts (qui ne sont pas natifs, tu les crées toi-même). Claude Code bouge vite : le juge de paix reste de taper / dans l'appli pour voir ce qui est réellement actif chez toi.

ALes commandes Claude Code

Des commandes natives : tu les tapes directement dans l'invite, elles commencent par /. Voici les ~68 que je te donne avec confiance, rangées par intention. Les alias (autres noms de la même commande) sont en gris.

Attention, ceux-là ne sont pas des commandes natives : ce sont des raccourcis-prompts que tu définis toi-même (dans tes instructions / ton CLAUDE.md, ou en les tapant tels quels). Aucun n'est officiel, mais ils transforment Claude en boîte à outils réflexe.

★ = déjà vu dans des listes publiques  ·  sans ★ = proposé, à câbler dans ta config.
