Le monteur vidéo gratuit piloté par Claude Code

Le tuto d'installation complet : brancher ChatCut (ou sa version open source) sur Claude Code, monter en parlant, exporter en local.

US Par Ugo Sartini

Tu vas installer un vrai monteur vidéo (timeline, pistes, transitions, sous-titres, export) et le piloter en parlant à Claude Code. Tu dis « coupe les silences, sous-titre en français, traduis en anglais », l'agent écrit les modifications dans le projet, tu relis, tu corriges, tu exportes sur ta machine. Voici le tuto complet, les deux chemins possibles, et surtout : ce qui est réellement gratuit et ce qui ne l'est pas.

Le principe à retenir : l'agent ne « génère » pas une vidéo figée. Il modifie un projet qui reste éditable : chaque coupe, chaque sous-titre, chaque transition atterrit sur une piste que tu peux reprendre à la main ou annuler.

1Deux chemins, choisis le tien

Il existe deux applications différentes. Elles se ressemblent, elles ne sont pas éditées par les mêmes personnes, et elles ne se paient pas pareil. Ne les confonds pas.

Chemin A : ChatCut. Le produit commercial (chatcut.io). Tu télécharges l'app, tu crées un compte, et un plugin officiel branche Claude Code ou Codex dessus. Le plus simple : rien à compiler, l'authentification est gérée pour toi, tu n'as pas de clé API à fournir.

Chemin B : OpenChatCut. Une alternative open source indépendante (openchatcut.com, licence AGPL-3.0), non affiliée au produit commercial. Tout tourne chez toi, tes projets et tes médias restent sur ton disque. Gratuit au sens strict, mais si tu veux les fonctions IA (transcription, génération), c'est toi qui branches tes propres services.

2Chemin A : brancher ChatCut sur Claude Code

Ce qu'il te faut. Claude Code en version 2.x (l'app desktop ou le terminal), git installé, et un compte sur chatcut.io. Vérifie d'abord que la commande répond :

À coller dans ton terminal :claude --version

La méthode paresseuse (recommandée). Ouvre Claude Code et dis-lui simplement, en anglais, d'aller lire la doc d'installation officielle et de tout faire pour toi :

Le message à envoyer à Claude Code :Read chatcut.io/claude to install the ChatCut plugin and set up a new task for me.

La méthode manuelle. Si tu préfères voir ce qui se passe, ce sont trois commandes. La première ajoute le dépôt officiel du plugin comme « marketplace », la deuxième installe le plugin, la troisième connecte ton compte (ça ouvre une page de connexion dans ton navigateur).

Les 3 commandes, dans l'ordre :claude plugin marketplace add https://github.com/ChatCut-Inc/agent-plugin.git
claude plugin install chatcut@chatcut-inc
claude mcp login plugin:chatcut:chatcut

Le détail complet de la procédure, y compris les cas d'erreur, est publié dans le dépôt : docs/claude-code-install.md.

Tu es sur Codex plutôt que Claude Code ? Le même dépôt contient un dossier codex/ avec le plugin équivalent, et la marche à suivre est sur chatcut.io/chatgpt. La connexion se fait avec codex mcp login chatcut.

Deux détails qui coincent : (1) la connexion demande un vrai terminal interactif, si tu la lances depuis une session web ou un environnement distant, ça échoue, il faut être sur ta machine ; (2) l'expérience complète (voir l'éditeur en direct pendant que l'agent travaille) passe par l'app desktop de Claude Code. En terminal seul, tu installes et tu pilotes, mais tu ouvres l'éditeur à la main.

3Chemin B : OpenChatCut, 100 % chez toi

Le plus rapide : télécharger l'installeur depuis la page Releases du projet. Il y a un DMG pour Mac Apple Silicon, un pour Mac Intel, et un installeur Windows x64.

Sur Mac, prépare-toi à un blocage. Les paquets macOS ne sont pas encore signés ni notarisés : au premier lancement, le système va refuser d'ouvrir l'app. Il faut l'autoriser manuellement (clic droit > Ouvrir, puis confirmer dans Réglages > Confidentialité et sécurité). Ce sont des builds jeunes, en développement actif : assume-le avant de mettre un projet client dessus.

La version « depuis la source », si tu veux la dernière version et voir tourner le code. Il te faut Node.js en version 24, pas 22, pas 26, la 24, le projet le vérifie.

Installation depuis la source :git clone https://github.com/0xsline/OpenChatCut.git
cd OpenChatCut
npm install
cp .env.example .env.local
npm run devL'éditeur s'ouvre ensuite sur http://localhost:5199. Pour la version bureau : npm run desktop:dev.

Brancher Claude Code dessus. OpenChatCut expose une porte d'entrée locale pour les agents. Une seule commande suffit à l'y connecter :

Connexion agent :claude mcp add --transport http openchatcut http://localhost:5199/api/external-mcp/mcpSur Codex, ajoute plutôt ces deux lignes à ta configuration :[mcp_servers.openchatcut]
url = "http://localhost:5199/api/external-mcp/mcp"
Le réflexe qui évite 90 % des « ça marche pas » : lance OpenChatCut et ouvre le projet concerné avant de demander quoi que ce soit à l'agent. Lister ou créer des projets fonctionne à distance, mais toucher à la timeline exige que le projet soit ouvert.

Sur les deux liens que je t'ai envoyés. Le dépôt frog923/openchatcut est une copie (un « fork ») du projet original. Pour être sûr d'avoir les mises à jour, pars du dépôt source : github.com/0xsline/OpenChatCut. Et ChatCut-Inc/agent-plugin, c'est le dépôt officiel du plugin du chemin A : celui que la commande d'installation va chercher.

4Les phrases qui font le boulot

Une fois branché, tu ne cliques plus, tu demandes. Voici des consignes qui fonctionnent bien : remarque qu'elles sont précises et vérifiables, c'est là toute la différence entre un montage utilisable et une bouillie.

  • « Transcris la vidéo, puis supprime les silences et les hésitations directement depuis le texte. »
  • « Génère les sous-titres en français, style lisible, puis traduis-les en anglais sur une seconde piste. »
  • « Ajoute une transition entre les clips 3 et 4, et un léger zoom avant sur les 2 premières secondes. »
  • « Recadre le projet en vertical pour Instagram et repositionne le sujet au centre. »
  • « Inspecte les images à 1 s, 6 s et 11 s et dis-moi ce qui cloche avant que j'exporte. »
  • « Exporte en MP4, plus le fichier de sous-titres SRT à part. »
Règle de travail : une demande = une intention. « Nettoie ma vidéo » ne veut rien dire. « Coupe les silences de plus d'une demi-seconde » est exécutable, et surtout : tu peux vérifier que ça a été fait.

5Gratuit jusqu'où, exactement

C'est la question honnête, et la réponse est simple : le travail de monteur est gratuit, la fabrication de pixels ne l'est pas.

Ce que tu faisÇa coûte ?
Monter, couper, réordonner sur la timeline★ Non
Transitions, effets, zooms, étalonnage★ Non
Sous-titres, traduction, export SRTSelon le service branché
Export local (MP4, audio, SRT, projet)★ Non
Générer de la vidéo IA, une voix, de la musiqueOui : c'est là que ça se paie
La nuance à ne pas rater : côté ChatCut, ton compte gère l'accès, tu n'as aucune clé à fournir. Côté OpenChatCut, le montage local ne demande rien du tout, mais les fonctions connectées (transcription, génération d'images ou de voix) restent éteintes tant que tu n'as pas renseigné toi-même les services correspondants. L'app te le dira explicitement plutôt que d'échouer en silence.

6Les 4 pièges à connaître avant de te lancer

  • Version de Node. Le chemin B exige Node 24. Une autre version et l'installation refuse de démarrer.
  • Mac non signé. Prévois l'étape d'autorisation manuelle au premier lancement d'OpenChatCut.
  • Ne publie pas ta porte d'entrée locale. Le pont pour agents est prévu pour une personne sur une machine. Si tu l'exposes sur Internet, protège-le par un jeton, sinon n'importe qui pilote ton éditeur.
  • Licence AGPL. Tu utilises OpenChatCut librement pour ton propre contenu. Si un jour tu le redistribues ou le proposes en service à des clients, cette licence t'impose des obligations : lis-la avant de bâtir une offre dessus.
Par où commencer, concrètement : si tu veux monter ta prochaine vidéo ce soir, prends le chemin A, trois commandes et tu parles à ton monteur. Si ton sujet c'est la maîtrise (données sensibles, zéro dépendance, code auditable), prends le chemin B et compte une soirée d'installation. Dans les deux cas, la compétence que tu construis est la même : savoir donner des consignes exécutables à un agent. C'est ça qui se transfère à tout le reste de ton activité.
