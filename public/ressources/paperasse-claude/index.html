Installer Paperasse sur Claude en 5 minutes

Six skills d'expert français pour ta compta, ta fisca, ton notariat et ta copro, branchés sur les sources officielles de l'État.

US Par Ugo Sartini

Tu demandes à Claude : « calcule les frais de notaire pour un appartement ancien à 320 000 € à Paris ». Il te sort le détail DMTO, émoluments, CSI, débours, avec le bon barème. Ou : « mon syndic veut voter 85 000 € de ravalement, quelle majorité ? ». Il te répond avec la loi de 1965 en référence. Ce n'est pas un prompt magique. C'est un skill.

Paperasse, c'est un projet open source (licence MIT, gratuit) qui transforme Claude en expert de l'administratif français : compta, contrôle fiscal, audit, fiscalité des particuliers, notariat, copropriété. Le truc malin du projet, ce n'est pas la liste des métiers couverts. C'est qu'il ne raconte jamais n'importe quoi : chaque skill est calibré pour ne répondre que sur ce qu'il maîtrise, sources légales à l'appui, et pour refuser poliment le reste.

Ce document est le mode d'emploi complet. Deux méthodes d'installation selon ton profil, cinq prompts pour tester, le branchement aux sources officielles de l'État, et les limites à connaître avant de t'en servir devant un client.

Compte 5 minutes. La méthode 1 ne demande aucune compétence technique : pas de terminal, pas de code, pas de carte bancaire. La méthode 2 prend 15 à 20 minutes la première fois et débloque l'automatisation complète.

3Méthode 1 : installer Paperasse sur Claude

Cette méthode passe par la fonctionnalité Projets du chat Claude. Compte gratuit ou Pro, les deux fonctionnent.

Étape 1 : récupérer les skills

Le projet est public : github.com/romainsimon/paperasse. Sur la page du dépôt, bouton vert Code → Download ZIP. Tu récupères une archive dans ton dossier Téléchargements.

Double-clique dessus pour la dézipper. Sur Mac, ça se fait tout seul. Sur Windows : clic droit → « Extraire tout ». Tu obtiens un dossier qui contient un sous-dossier par skill : comptable, controleur-fiscal, commissaire-aux-comptes, fiscaliste, notaire, syndic.

Étape 2 : créer un projet sur Claude

Connecte-toi sur claude.ai. Dans le menu de gauche : Projects → New project. Donne-lui un nom (« Paperasse », ou « Mon assistant fiscal »). Dans le champ instructions du projet, colle exactement ceci :

Tu es un assistant spécialisé en administratif français.
Tu disposes des skills Paperasse dans les fichiers du projet.

Avant de répondre à une question, consulte le fichier SKILL.md
du skill concerné (comptable, controleur-fiscal,
commissaire-aux-comptes, fiscaliste, notaire ou syndic).

Tu ne réponds que sur ce que les skills couvrent.
Pour tout le reste, tu rediriges vers un professionnel.

Enregistre.

Étape 3 : attacher les fichiers au projet

Dans le panneau de droite, section Project knowledge : Add content → Upload files. Entre dans chacun des 6 sous-dossiers et uploade le fichier SKILL.md qui s'y trouve. Ajoute aussi le README.md de la racine, pour donner le contexte global.

Bonus qui change tout : uploade également le contenu des sous-dossiers references/ (textes de loi, barèmes, procédures détaillées). C'est plus long, mais ça améliore drastiquement la qualité des réponses sur les cas pointus. Astuce : tu peux glisser-déposer plusieurs fichiers d'un coup, pas besoin de les charger un par un.

Étape 4 : tester ton installation

Ouvre une nouvelle conversation dans ton projet et lance ces deux tests :

> Calcule les frais de notaire pour un appartement ancien
  à 320 000 euros à Paris. Détaille DMTO, émoluments, CSI, débours.

> Mon CA cumulé sur l'année est de 32 000 euros HT en prestations
  de services. Suis-je proche du seuil de TVA ? Quel régime ?

Le premier doit déclencher le skill notaire, avec le taux DMTO applicable à Paris et le barème des émoluments. Le second doit déclencher le skill comptable, avec les seuils en vigueur et un raisonnement sur les régimes (franchise en base, réel simplifié, réel normal).

Comment tu sais que c'est bon : les réponses arrivent structurées et chiffrées, pas en prose vague. Si Claude te répond « cela dépend de plusieurs facteurs », les fichiers ne sont pas lus. Revérifie l'étape 3.

4Méthode 2 : installer Paperasse sur Claude Code

Claude Code, c'est l'agent Claude qui tourne dans ton terminal. Plus puissant : il exécute les scripts du projet, branche tes comptes Qonto et Stripe, et automatise une clôture annuelle complète.

Étape 1 : installer Claude Code

Il te faut Node.js en version 18 ou plus (prends la version LTS). Ensuite, dans ton terminal :

npm install -g @anthropic-ai/claude-code
claude

La première fois, Claude Code ouvre un onglet navigateur pour valider la connexion à ton compte Anthropic. Suis les instructions à l'écran. Détails sur la page officielle.

Étape 2 : l'installation guidée (la plus simple)

Le raccourci : tu laisses Claude Code faire le travail. Place-toi dans un dossier de ton choix, lance claude, puis colle ce prompt :

J'ai téléchargé l'archive du projet Paperasse dans mon dossier
Téléchargements. Dézippe-la, copie les 6 skills (comptable,
controleur-fiscal, commissaire-aux-comptes, fiscaliste, notaire,
syndic) dans le bon dossier ~/.claude/skills/.

Lance ensuite le setup pour configurer mon environnement
(raison sociale, SIREN, régime TVA, dates d'exercice si je suis
entrepreneur, ou skip si je suis particulier).

Tu réponds aux questions de configuration, et c'est terminé.

Étape 3 (alternative) : l'installation manuelle

Si tu préfères tout contrôler, voici la version ligne par ligne. Tu peux coller le bloc entier.

# 1. Se placer dans le dossier Téléchargements
cd ~/Downloads

# 2. Dézipper l'archive téléchargée depuis GitHub
unzip paperasse-master.zip

# 3. Créer le dossier skills de Claude Code s'il n'existe pas
mkdir -p ~/.claude/skills

# 4. Entrer dans le dossier dézippé
cd paperasse-master

# 5. Copier les 6 skills
cp -r comptable ~/.claude/skills/
cp -r controleur-fiscal ~/.claude/skills/
cp -r commissaire-aux-comptes ~/.claude/skills/
cp -r fiscaliste ~/.claude/skills/
cp -r notaire ~/.claude/skills/
cp -r syndic ~/.claude/skills/

# 6. Installer les dépendances pour les scripts (FEC, PDF)
npm install
Sur Windows : remplace cd ~/Downloads par cd "%USERPROFILE%\Downloads" dans PowerShell, et utilise copy au lieu de cp si tu n'as pas Git Bash installé.

Étape 4 : tester

> Quels skills Paperasse sont disponibles ?

> Calcule les droits de succession pour 3 enfants héritant
  d'un patrimoine net de 600 000 euros, sans donation antérieure.

Claude Code doit lister les 6 skills, puis dérouler le calcul avec barème progressif, abattement de 100 000 € par enfant, et droits dus par héritier.

5Cinq premiers prompts à tester

Quelle que soit la méthode, voici cinq questions qui montrent l'étendue réelle du truc. Lance-les dans l'ordre : tu vas voir la profondeur descendre d'un cran à chaque fois.

1. Notaire : frais d'achat immobilier.

> Je veux acheter un appartement neuf à 450 000 euros à Lyon, en VEFA.
  Calcule les frais de notaire complets : DMTO réduits, émoluments,
  CSI, débours. Donne-moi aussi le coût final tout compris.

2. Notaire : succession.

> Ma mère est décédée. Nous sommes 2 enfants. L'actif net est de
  800 000 euros (résidence principale 450k + comptes 350k).
  Calcule les droits de succession par enfant, en tenant compte
  de l'abattement de 100 000 euros.

3. Fiscaliste particuliers : RSU et BSPCE.

> J'ai vesté 50 RSU à 80 euros l'unité chez une boîte tech française.
  Mon TMI est de 41%. Comment je déclare ça, et combien je vais payer
  d'IR + prélèvements sociaux ?

4. Comptable : TVA et seuils.

> Je suis en EURL, exercice civil, prestations de services.
  CA prévisionnel : 42 000 euros HT. Suis-je éligible à la
  franchise en base ? Quel régime de TVA conseilles-tu ?

5. Syndic : charges de copropriété.

> Mon syndic veut faire voter en AG des travaux de ravalement à
  85 000 euros. Quelle majorité est requise ? Quelles règles
  doit-il respecter pour l'appel de fonds ?

6Pourquoi il n'invente pas (la vraie valeur du projet)

N'importe qui peut écrire « tu es un expert-comptable » dans un prompt. Ce qui fait la différence de Paperasse, c'est le cadrage. Quatre mécanismes, concrets, que tu peux reprendre pour tes propres skills.

Les sources officielles sont intégrées. Chaque skill embarque ou pointe vers les bons textes : le Plan Comptable Général complet (800+ comptes) via data.gouv.fr, la doctrine BOFiP, les normes NEP de la CNCC, les articles du CGI, la loi du 10 juillet 1965 et le décret de 2005 pour la copropriété, la base Sirene, et le calendrier fiscal d'impots.gouv.fr.

Il refuse poliment ce qu'il ignore. Demande au skill notaire de te conseiller sur ta déclaration crypto : il te renvoie vers le skill fiscaliste. Demande au comptable de rédiger un acte de donation : il te renvoie vers le notaire. Pas d'invention, pas de mélange des cartes. C'est exactement ce qu'un Claude sans skill ne ferait pas : il tenterait une réponse.

Il connaît sa date de péremption. Chaque skill porte un champ de dernière mise à jour. Au-delà de 6 mois, l'agent affiche un avertissement et va vérifier en ligne les chiffres sensibles (seuils TVA, taux d'IS, plafonds micro) avant de répondre. Le législateur français change les règles plus souvent qu'on ne change de mot de passe.

Il vérifie le contexte avant de calculer. Avant toute clôture, liasse ou simulation, le skill comptable demande la raison sociale, le SIREN, la forme juridique, le régime TVA et les dates d'exercice. Le notaire demande la situation maritale, le nombre d'enfants et la composition du patrimoine. Jamais à l'aveugle.

Le vrai enseignement : ce n'est pas un nouveau modèle d'IA. C'est la possibilité d'écrire du métier en texte simple et de le glisser à Claude. Un skill, c'est un dossier avec un fichier qui décrit le domaine couvert, les sources à mobiliser, les cas d'usage attendus, et surtout les garde-fous. Tu peux en écrire un pour ton métier en quelques heures.

7Brancher les sources officielles de l'État

À ce stade, ton Claude raisonne avec ce que les skills contiennent. C'est déjà beaucoup. Mais dès qu'il faut une information à jour et vérifiable (le texte exact d'un article, une jurisprudence récente, l'immatriculation d'une société), il te faut une source vivante, branchée en direct.

Bonne nouvelle : l'État et quelques services tiers exposent désormais leurs bases sous une forme que Claude sait interroger tout seul. Voici les adresses qui existent réellement aujourd'hui.

data.gouv.fr : public, sans compte, sans clé. La plateforme d'open data de l'État expose son propre point d'accès à l'adresse https://mcp.data.gouv.fr/mcp, en lecture seule. C'est le meilleur endroit pour tester, puisqu'il n'y a ni inscription ni carte bancaire. Documentation officielle.

Ce que l'équipe dit elle-même : le service est encore expérimental, son périmètre peut évoluer, et les réponses peuvent être incomplètes ou erronées. Pour un usage sérieux, ils recommandent leurs API structurées. C'est écrit dans leur propre documentation. Dis-le avant qu'on ne le découvre à ta place.

OpenLegi : le juridique et les entreprises. Service tiers (openlegi.fr), une adresse par périmètre :

PérimètreCe que ça couvreAdresse
LégifranceCodes, JORF, jurisprudence, LODAmcp.openlegi.fr/legifrance/mcp
RNERegistre national des entreprisesmcp.openlegi.fr/rne/mcp
BODACCAnnonces, procédures collectivesmcp.openlegi.fr/bodacc/mcp
BOFiPDoctrine fiscalemcp.openlegi.fr/bofip/mcp
EUR-LexLégislation européennemcp.openlegi.fr/eurlex/mcp

Deux modes de connexion : OAuth (recommandé si tu branches ça sur ton compte claude.ai) ou un jeton personnel placé dans l'adresse ou l'en-tête. C'est ce second mode qui convient à un agent qui tourne sur un serveur. Leur guide de démarrage.

Attention au budget : tous les périmètres ne sont pas au même régime. Plusieurs sources annoncent RNE, EUR-Lex et Judilibre comme réservés à un abonnement. Confirme avant d'annoncer un prix à qui que ce soit.

Le branchement, concrètement

Sur claude.ai (méthode 1), ça se fait dans les réglages de connecteurs : tu colles l'adresse, tu autorises, c'est fini. Rien à coder.

Si tu construis un agent qui tourne sur un serveur, l'API d'Anthropic sait se connecter seule à une source distante : tu lui donnes l'adresse, elle va y chercher l'information quand la question le demande. Trois réglages, dans le fichier qui fabrique la réponse :

  • déclarer la source, avec son adresse et un nom, dans mcp_servers ;
  • déclarer aussi la trousse d'outils correspondante dans tools, sous la forme mcp_toolset, en reprenant exactement le même nom ;
  • activer l'option, encore en bêta, via l'en-tête mcp-client-2025-11-20.
Le détail que personne n'écrit : les deux moitiés sont obligatoires. Déclarer la source sans déclarer la trousse d'outils fait échouer la requête, et le message d'erreur n'aide pas. C'est l'aller-retour qui coûte une soirée à celui qui découvre. La doc officielle est la seule à le dire clairement : la page MCP connector. Une bêta bouge : relis cette page le jour où tu montes le tien, plutôt que de recopier une valeur trouvée ailleurs.
Un piège de raisonnement : les connecteurs que tu as branchés dans ton compte Claude ne suivent pas sur un agent que tu déploies. Ce sont deux plomberies séparées. Ton compte, c'est pour tes conversations à toi. Un agent tape sur l'API avec ses propres accès, qu'il faut lui donner explicitement.

8Les limites, à lire avant de t'en servir

Paperasse est un outil d'aide à la décision et de préparation. Ce n'est pas un substitut à un professionnel inscrit à l'Ordre. Ce point-là n'est pas une précaution de langage : c'est ce qui sépare un usage intelligent d'un problème.

Ce qu'il ne fera jamais à ta placeCe qu'il fait très bien
Signer une liasse fiscale, un FEC, un acte notarié ou des comptes annuels★ Comprendre ta situation et te donner le bon raisonnement
Déposer des documents sur Infogreffe ou impots.gouv.fr (authentification personnelle requise)Préparer un brouillon de liasse, de courrier, d'acte ou de calcul
Engager ta responsabilité légale ou celle de ton entrepriseT'éviter une heure de recherche sur une case fiscale obscure
Remplacer un expert-comptable, un avocat fiscaliste, un CAC ou un notaire sur une situation complexeAnticiper les risques d'un contrôle, d'une succession ou d'un montage
Authentifier un acte (monopole du notaire en exercice)★ Te rendre crédible et préparé en rendez-vous chez ton conseil
Accéder à FICOBA, au RBE ou aux registres réservés aux prosTe faire gagner le temps de la première mise à plat
La règle : pour toute décision qui engage légalement (signature d'acte, dépôt officiel, déclaration validée), passe par un pro avec une assurance RC Pro et un numéro SIRET. Paperasse t'aide à arriver chez ce pro en sachant ce que tu fais. C'est déjà énorme, et c'est souvent là que se joue la qualité du rendez-vous.

9Aller plus loin

Brancher Qonto et Stripe (méthode 2 uniquement). Si tu veux que Claude récupère tes transactions bancaires et tes paiements automatiquement, crée un fichier .env à la racine du dossier du projet avec tes clés :

QONTO_ID=ton-slug-organisation
QONTO_API_SECRET=ton-secret-qonto
STRIPE_SECRET=sk_live_...

Où les trouver : côté Qonto, Settings → Integrations → API (tu y trouves l'ID d'organisation et tu peux générer une clé). Côté Stripe, Developers → API keys → ta secret key live. Ensuite, dans Claude Code, tu demandes simplement de récupérer les transactions sur l'année et de lancer la catégorisation automatique en PCG.

Rappel de sécurité : une clé API bancaire ou de paiement ne se colle jamais dans une conversation, ni dans un document partagé. Elle vit dans un fichier .env local, sur ta machine, et nulle part ailleurs.

Mettre à jour les skills. Le projet évolue et son auteur met à jour les skills quand la loi change. Sur claude.ai : retélécharge l'archive et re-uploade les fichiers modifiés dans ton projet. Sur Claude Code : dis simplement « mets à jour les skills Paperasse vers la dernière version », il s'en charge.

Créer les tiens. C'est là que ça devient intéressant pour une entreprise. Une fois que tu as compris le format, tu écris un skill pour ton métier : le domaine couvert, les sources à mobiliser, les cas d'usage, les garde-fous. Et tu le branches exactement de la même manière.
