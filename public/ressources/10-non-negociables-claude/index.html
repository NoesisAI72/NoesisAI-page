Mes 10 non négociables avec Claude

Les 10 choses que j'utilise systématiquement dans Claude Code, avec les étapes exactes pour les installer et les activer, de la plus simple à la plus avancée. À jour au 24 novembre 2026.

US Par Ugo Sartini

10 non négociables, 0 blabla, 1 seul endroit où les retrouver. Ce sont les 10 choses que j'utilise systématiquement dans Claude Code, rangées de la plus simple à la plus avancée.

Pour chacune : à quoi elle sert, les étapes exactes, et le plus souvent un message prêt à coller pour que Claude l'installe à ta place. Dans ce cas, tu n'as aucun fichier à écrire à la main.

Du 1 au 5Les bases pour démarrer

1Créer des projets

Pour que Claude connaisse tes règles sans que tu aies à les répéter à chaque fois.

1

Crée un fichier CLAUDE.md dans le dossier de ton projet.

2

Note dedans tes outils, tes conventions, et ce que tu ne veux pas qu'il fasse.

3

C'est tout : Claude Code le lit au début de chaque session. Garde-le court, sous 200 lignes, sinon il le suit moins bien.

Plus rapide : tape /init, Claude regarde ton dossier et écrit une première version. Ou réponds à ses questions :

À coller dans Claude Code
Crée le fichier CLAUDE.md de ce projet.
Avant d'écrire, pose-moi 5 questions, une par une : ce que fait mon activité, les outils que j'utilise, mes règles à respecter, ce que tu ne dois jamais faire sans mon accord, et le ton à employer.
Garde le fichier sous 100 lignes, puis montre-le-moi avant de l'enregistrer.

Sur claude.ai, la fonction la plus proche s'appelle Projets : tu y mets tes consignes et tes documents. Pour aller plus loin : les 5 étages du contexte dans Claude. Source : documentation officielle.

2Les skills

Des instructions que tu écris une fois et que tu réutilises avec une commande.

1

Crée le fichier .claude/skills/ton-skill/SKILL.md.

2

Écris le nom, quand l'utiliser, et les étapes à suivre.

3

Appelle-le en tapant /ton-skill dans le chat. Claude peut aussi le déclencher seul quand ta demande correspond.

Un exemple complet, à adapter. On le réutilise au point 9 :

SKILL.md
---
name: verifier-nouveaux-leads
description: Vérifie les nouvelles demandes de contact et prépare une réponse. À utiliser quand je parle de nouveaux leads ou de demandes entrantes.
---

1. Cherche les demandes reçues depuis la dernière vérification.
2. Pour chacune, note le nom, l'entreprise, le besoin et l'urgence.
3. Prépare un brouillon de réponse en 5 lignes maximum.
4. N'envoie rien. Termine par un tableau récapitulatif.

Pour un skill utilisable dans tous tes projets, range-le dans ~/.claude/skills/. Pour aller plus loin : Skills Claude, le guide complet. Source : documentation officielle.

3Les subagents

Déléguer des tâches en parallèle sans perdre le fil principal.

1

Crée .claude/agents/nom.md avec le nom, la description et les outils autorisés.

2

En dessous, écris les instructions : comment cet agent doit travailler.

3

Appelle-le par son nom, ou laisse Claude le choisir tout seul si la tâche correspond.

Chaque subagent travaille dans sa propre conversation et ne te rapporte que le résultat. Le plus simple est de le décrire :

À coller dans Claude Code
Crée un subagent de projet nommé relecteur-devis.
Son rôle : relire un devis avant envoi et lister les erreurs de calcul, les lignes manquantes et les formulations ambiguës.
Il peut lire les fichiers, jamais les modifier.
Enregistre-le dans .claude/agents/, puis montre-moi le fichier.

Ne donne à chaque agent que les outils dont il a besoin. Pour aller plus loin : monter une équipe d’agents dans Claude Code. Source : documentation officielle.

4Les hooks

Des règles qui se déclenchent toutes seules quand quelque chose de précis se passe.

1

Ouvre .claude/settings.json (dans le projet), ou ~/.claude/settings.json pour tous tes projets.

2

Ajoute une clé hooks avec l'événement : par exemple PostToolUse après une modification de fichier, Notification quand Claude t'attend.

3

Mets là la commande qui doit tourner toute seule, par exemple tes tests. Tape /hooks pour vérifier qu'elle est bien prise en compte.

Un bon premier hook : une alerte sur ton Mac dès que Claude a besoin de toi.

settings.json · Mac
{
  "hooks": {
    "Notification": [
      {
        "matcher": "",
        "hooks": [
          {
            "type": "command",
            "command": "osascript -e 'display notification \"Claude a besoin de toi\" with title \"Claude Code\"'"
          }
        ]
      }
    ]
  }
}
Tu es sur Windows, ou ton fichier contient déjà des réglages ? Demande simplement : « Ajoute un hook qui m'affiche une notification quand tu attends ma réponse, sans toucher à mes autres réglages. »

Un hook lance une vraie commande sur ton ordinateur : n'en colle jamais un que tu ne comprends pas. Source : documentation officielle.

5Le MCP

Connecter Claude à tes vrais outils : boîte mail, agenda, CRM, facturation.

1

Cherche le serveur MCP de l'outil que tu veux ajouter, de préférence celui de l'éditeur.

2

Dans le terminal : claude mcp add nom -- commande pour un serveur installé sur ton ordinateur, ou claude mcp add --transport http nom adresse pour un serveur en ligne.

3

Ouvre une nouvelle session Claude Code, puis tape /mcp : l'outil apparaît, et c'est là que tu le relies à ton compte si besoin.

Sans terminal : dans l'application Claude, clique sur + à côté de la zone de texte, puis ajoute un connecteur. Un connecteur est un serveur MCP déjà préparé, et ceux de ton compte claude.ai marchent aussi dans Claude Code.

N'ajoute que des serveurs en qui tu as confiance : ils voient ce que tu leur donnes. En vidéo : Claude branché sur Google Maps. Source : documentation officielle.

Du 6 au 10Pour vraiment en tirer le maximum

6Choisir le bon modèle

Pas toujours le plus cher : celui qui est le plus adapté à la tâche.

1

Tape /model pour voir les options de ton abonnement.

2

Choisis selon la tâche, avec le tableau ci-dessous.

3

Avant de changer de modèle, essaie /effort : c'est le réglage qui dit à Claude combien réfléchir.

ModèlePour quoi
HaikuLes tâches simples et répétitives : trier, extraire, reformuler. Le plus rapide.
SonnetLe quotidien : celui du milieu.
OpusLes grosses tâches qui demandent du raisonnement.
FableLes tâches les plus dures et les plus longues. Le plus puissant, si ton plan l'a : selon l'offre, il consomme des crédits en plus.

Pour aller plus loin : quel modèle choisir, tâche par tâche. Source : documentation officielle.

7Compacter la conversation

Quand la conversation se remplit, la compresser plutôt que tout perdre.

1

Tape /compact quand la conversation devient longue.

2

Claude résume l'essentiel et continue avec ça.

3

Souvent, ça se déclenche tout seul, sans que tu le demandes.

Le plus utile : lui dire ce qu'il doit absolument garder.

À coller dans Claude Code
/compact Garde les décisions prises, les fichiers modifiés et ce qu'il reste à faire.

/context montre ce qui prend de la place. /clear repart de zéro : à utiliser quand tu changes de sujet. Source : documentation officielle.

8Le mode plan

Pour ce qui est risqué : qu'il montre le plan avant de toucher à quoi que ce soit.

1

Dans le terminal, appuie sur Shift+Tab jusqu'à voir plan mode on en bas de l'écran. Le nombre d'appuis dépend du mode de départ : deux depuis le mode manuel.

2

Vérifie les étapes proposées : à ce stade, il n'a encore rien modifié.

3

Valide seulement après, pour qu'il exécute.

Plus direct : commence ton message par /plan. Dans l'application Claude, choisis Plan dans le sélecteur sous la zone de texte.

À activer dès qu'il y a des données clients, une suppression ou un envoi. Source : documentation officielle.

9Les loops

Des tâches qui tournent toutes seules à intervalle régulier.

1

Tape /loop + l'intervalle + ce que tu veux qu'il répète.

2

Exemple : /loop 30m /verifier-nouveaux-leads, le skill du point 2.

3

Pour l'arrêter, demande-le simplement : « arrête la boucle des leads ».

À savoir : une loop ne tourne que si Claude Code est ouvert et ton ordinateur allumé, et elle s'arrête d'elle-même au bout de 7 jours. Chaque passage consomme ton quota : choisis un intervalle assez large.

Pour que ça tourne sans toi : dans l'application Claude, onglet Code, ouvre les tâches planifiées (Scheduled, ou Routines selon ta version) et crée une tâche. Une tâche locale demande que l'ordinateur soit allumé et l'application ouverte. Une tâche cloud tourne même ordinateur éteint.

En vidéo : les 5 niveaux d’autonomie des agents IA. Pour aller plus loin : le loop qui corrige son propre travail. Source : documentation officielle.

10OpenRouter, le filet de secours open source

Quand tu n'as plus de tokens, tu continues avec un autre modèle, y compris open source.

1

Crée un compte sur openrouter.ai, ajoute des crédits et génère ta clé API.

2

Plus besoin de proxy : OpenRouter se branche maintenant en direct. Ajoute le bloc ci-dessous dans .claude/settings.local.json, avec ta clé.

3

Tape /logout, relance Claude Code, puis /status : l'adresse OpenRouter doit apparaître. Tu choisis ensuite ton modèle avec /model.

settings.local.json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://openrouter.ai/api",
    "ANTHROPIC_AUTH_TOKEN": "ta-cle-openrouter",
    "ANTHROPIC_API_KEY": "",
    "CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY": "1"
  }
}

Pour revenir à ton abonnement : retire ce bloc, relance Claude Code et tape /login. Le proxy communautaire claude-code-router existe toujours, mais il n'est plus indispensable.

Attention : ce n'est pas une fonctionnalité officielle d'Anthropic, qui ne prend pas en charge les modèles autres que Claude dans Claude Code. OpenRouter ne garantit le bon fonctionnement qu'avec les modèles Claude servis par Anthropic. Avec un modèle open source, garde des tâches simples. La consommation est facturée par OpenRouter, en plus de ton abonnement, et ta clé ne se partage jamais.

L'option officielle quand tu atteins ta limite : /usage-credits, pour continuer avec Claude en crédits payants. Sources : guide OpenRouter et position d’Anthropic.

Installe-les un par un

Pas besoin de tout mettre en place le même jour. Commence par les projets et les skills, et ajoute le reste au fur et à mesure que tu en as besoin.
